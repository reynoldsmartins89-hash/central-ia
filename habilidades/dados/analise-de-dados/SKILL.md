# Análise de dados

## Fluxo
1. Entender a pergunta de negócio
2. Descrever os dados disponíveis e problemas de qualidade
3. Propor análises (e código pandas/matplotlib quando útil)
4. Interpretar resultados com cautela estatística
5. Recomendar ações e indicadores para acompanhar

Cálculos devem ser feitos por código, não "de cabeça" pelo modelo.
