# Habilidades

Biblioteca central de habilidades (skills) da Central de IA. Cada pasta é uma
categoria com um `DESCRIPTION.md`; cada subpasta é uma habilidade com um `SKILL.md`
(frontmatter `name` + `description`, no padrão Agent Skills — o mesmo formato
usado pelo Claude Code, Gemini CLI e Hermes Agent).

Os agentes em `agentes/agentes.toml` apontam para estas habilidades.
