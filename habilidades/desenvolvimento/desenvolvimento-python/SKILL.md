# Desenvolvimento Python

## Regras
- Código completo e executável, com instruções de execução no Windows (PowerShell).
- Segredos sempre via variáveis de ambiente (`.env`), nunca no código.
- Inclua ao menos um teste simples quando fizer sentido.
- Explique dependências novas antes de usá-las.
